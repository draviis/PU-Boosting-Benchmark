% Data availability
The processed benchmark results and numerical data required to reproduce
the reported analyses and figures are publicly available at
\url{https://github.com/draviis/PU-Boosting-Benchmark}.
The repository also provides source references and preparation code for
the original real-world datasets, which retain their respective terms
of use.

% Code availability
The source code used to generate the simulation scenarios, construct
the positive--unlabeled samples, fit the evaluated methods, and reproduce
the analyses and figures is publicly available at
\url{https://github.com/draviis/PU-Boosting-Benchmark}.
Original code is released under the MIT license; third-party components
retain their original licenses.
